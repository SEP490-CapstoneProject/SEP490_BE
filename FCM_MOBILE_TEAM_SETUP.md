## Firebase Project Setup

### Prerequisites

- Google Cloud Account
- Firebase Project (or create new)
- Service credentials for backend (provided by backend team)

### Step 1: Create Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com)
2. Click "Add project"
3. Enter project name: `recruitment-platform`
4. Choose region: `Southeast Asia` (for Vietnam)
5. Finish project setup

### Step 2: Add Apps to Firebase

#### For Android App

1. In Firebase Console, click **Android** icon
2. Enter Android package name: `com.recruitment.app`
3. Download `google-services.json`
4. Save to: `android/app/google-services.json`

#### For iOS App

1. In Firebase Console, click **iOS** icon
2. Enter iOS Bundle ID: `com.recruitment.app`
3. Download `GoogleService-Info.plist`
4. Add to Xcode: `ios/Runner/GoogleService-Info.plist`

### Step 3: Enable Cloud Messaging

1. Go to **Cloud Messaging** tab
2. Verify "Firebase Cloud Messaging API" is **Enabled**
3. Go to **Service Accounts** tab
4. Generate new private key (for backend team)

### Step 4: Dart Implementation

**lib/services/firebase_service.dart:**

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter_local_notifications/flutter_local_notifications.dart';
import 'firebase_options.dart'; // Generated by Firebase

class FirebaseService {
  static final FirebaseService _instance = FirebaseService._internal();

  factory FirebaseService() {
    return _instance;
  }

  FirebaseService._internal();

  final FirebaseMessaging _firebaseMessaging = FirebaseMessaging.instance;
  final FlutterLocalNotificationsPlugin _localNotifications = 
    FlutterLocalNotificationsPlugin();

  // Initialize Firebase and FCM
  Future<void> initialize() async {
    // Initialize Firebase
    await Firebase.initializeApp(
      options: DefaultFirebaseOptions.currentPlatform,
    );

    // Initialize local notifications
    const AndroidInitializationSettings androidSettings =
      AndroidInitializationSettings('@mipmap/ic_launcher');
    const DarwinInitializationSettings iosSettings =
      DarwinInitializationSettings(
        requestAlertPermission: true,
        requestBadgePermission: true,
        requestSoundPermission: true,
      );

    const InitializationSettings initSettings = InitializationSettings(
      android: androidSettings,
      iOS: iosSettings,
    );

    await _localNotifications.initialize(
      initSettings,
      onDidReceiveNotificationResponse: _handleNotificationTap,
    );

    // Request user permission
    final NotificationSettings settings = await _firebaseMessaging
      .requestPermission(
        alert: true,
        announcement: false,
        badge: true,
        carPlay: false,
        criticalAlert: false,
        provisional: false,
        sound: true,
      );

    if (settings.authorizationStatus == AuthorizationStatus.authorized) {
      print('User granted permission for notifications');
    } else if (settings.authorizationStatus == AuthorizationStatus.provisional) {
      print('User granted provisional permission for notifications');
    } else {
      print('User declined notification permission');
    }

    // Set up message handlers
    _setupMessageHandlers();

    // Register device token with backend
    await _registerDeviceToken();
  }

  // Setup message handlers
  void _setupMessageHandlers() {
    // Handle messages when app is in foreground
    FirebaseMessaging.onMessage.listen((RemoteMessage message) {
      print('Foreground message received: ${message.messageId}');
      _handleForegroundMessage(message);
    });

    // Handle notification tap when app was terminated
    FirebaseMessaging.instance.getInitialMessage().then((message) {
      if (message != null) {
        print('Terminated app notification tap: ${message.messageId}');
        _handleNotificationTap(message.data);
      }
    });

    // Handle notification tap when app was in background
    FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
      print('Background message notification tap: ${message.messageId}');
      _handleNotificationTap(message.data);
    });

    // Handle token refresh
    FirebaseMessaging.instance.onTokenRefresh.listen((newToken) {
      print('FCM token refreshed: $newToken');
      _registerDeviceToken();
    });
  }

  // Handle foreground messages
  Future<void> _handleForegroundMessage(RemoteMessage message) async {
    print('Title: ${message.notification?.title}');
    print('Body: ${message.notification?.body}');
    print('Data: ${message.data}');

    // Show local notification
    const AndroidNotificationDetails androidDetails =
      AndroidNotificationDetails(
        'recruitment_app',
        'Recruitment Notifications',
        channelDescription: 'Notifications from recruitment platform',
        importance: Importance.max,
        priority: Priority.high,
        playSound: true,
        enableVibration: true,
      );

    const DarwinNotificationDetails iosDetails = DarwinNotificationDetails(
      presentAlert: true,
      presentBadge: true,
      presentSound: true,
    );

    const NotificationDetails platformDetails = NotificationDetails(
      android: androidDetails,
      iOS: iosDetails,
    );

    await _localNotifications.show(
      message.hashCode,
      message.notification?.title ?? 'Notification',
      message.notification?.body ?? '',
      platformDetails,
      payload: jsonEncode(message.data),
    );
  }

  // Handle notification tap
  void _handleNotificationTap(dynamic payload) {
    String deepLink = '';

    if (payload is String) {
      deepLink = payload;
    } else if (payload is Map) {
      deepLink = payload['deepLink'] ?? '';
    }

    if (deepLink.isNotEmpty) {
      print('Handling deep link: $deepLink');
      // Handle deep link navigation (see Deep Linking section)
      _handleDeepLink(deepLink);
    }
  }

  // Register device token with backend
  Future<void> _registerDeviceToken() async {
    try {
      final token = await _firebaseMessaging.getToken();
      if (token == null) return;

      print('FCM Token: $token');

      // Get device info
      final deviceInfo = DeviceInfoPlugin();
      final deviceType = Platform.isAndroid ? 'Android' : 'iOS';

      // Call backend API to register token
      await _registerTokenWithBackend(
        token: token,
        deviceType: deviceType,
        appVersion: '1.0.0', // Get from package info
      );
    } catch (e) {
      print('Error registering device token: $e');
    }
  }

  // Call backend API to register token
  Future<void> _registerTokenWithBackend({
    required String token,
    required String deviceType,
    required String appVersion,
  }) async {
    try {
      final response = await http.post(
        Uri.parse('${ApiConstants.baseUrl}/api/device-tokens/register'),
        headers: {
          'Content-Type': 'application/json',
          'Authorization': 'Bearer ${AuthService().accessToken}',
        },
        body: jsonEncode({
          'token': token,
          'deviceType': deviceType,
          'appVersion': appVersion,
        }),
      );

      if (response.statusCode == 200) {
        print('Device token registered successfully');
      } else {
        print('Failed to register device token: ${response.statusCode}');
      }
    } catch (e) {
      print('Error registering device token with backend: $e');
    }
  }

  // Handle deep link navigation
  void _handleDeepLink(String deepLink) {
    // Parse deep link format: app://notification/123
    final Uri uri = Uri.parse(deepLink);
    
    if (uri.scheme == 'app' && uri.host == 'notification') {
      final notificationId = uri.pathSegments.isNotEmpty 
        ? uri.pathSegments.last 
        : null;
      
      if (notificationId != null) {
        // Navigate to notification details page
        navigateToNotificationDetails(notificationId);
      }
    }
  }

  // Unregister device token on logout
  Future<void> unregisterDeviceToken() async {
    try {
      final token = await _firebaseMessaging.getToken();
      if (token == null) return;

      final response = await http.delete(
        Uri.parse('${ApiConstants.baseUrl}/api/device-tokens/register/$token'),
        headers: {
          'Authorization': 'Bearer ${AuthService().accessToken}',
        },
      );

      if (response.statusCode == 200) {
        print('Device token unregistered successfully');
      }
    } catch (e) {
      print('Error unregistering device token: $e');
    }
  }

  // Get current FCM token
  Future<String?> getToken() async {
    return await _firebaseMessaging.getToken();
  }
}
```

**src/services/firebase.ts:**

```typescript
import messaging from '@react-native-firebase/messaging';
import { Platform } from 'react-native';
import DeviceInfo from 'react-native-device-info';
import { apiClient } from './api';
import { AuthService } from './auth';

export class FirebaseMessagingService {
  private static instance: FirebaseMessagingService;

  private constructor() {}

  static getInstance(): FirebaseMessagingService {
    if (!FirebaseMessagingService.instance) {
      FirebaseMessagingService.instance = new FirebaseMessagingService();
    }
    return FirebaseMessagingService.instance;
  }

  async initialize(): Promise<void> {
    // Request permission
    const authStatus = await messaging().requestPermission({
      ios: {
        alert: true,
        badge: true,
        sound: true,
        provisional: false,
        providesAppNotificationSettings: true,
      },
    });

    if (
      authStatus === messaging.AuthorizationStatus.AUTHORIZED ||
      authStatus === messaging.AuthorizationStatus.PROVISIONAL
    ) {
      console.log('Authorization status:', authStatus);
    } else {
      console.log('User declined notifications');
      return;
    }

    // Setup message handlers
    this.setupMessageHandlers();

    // Register device token
    await this.registerDeviceToken();
  }

  private setupMessageHandlers(): void {
    // Handle foreground messages
    const unsubscribeForeground = messaging().onMessage(async (remoteMessage) => {
      console.log('Foreground message:', remoteMessage);
      this.handleForegroundMessage(remoteMessage);
    });

    // Handle background messages (when app is closed)
    messaging().setBackgroundMessageHandler(async (remoteMessage) => {
      console.log('Background message:', remoteMessage);
      // FCM will automatically display the notification
    });

    // Handle notification tap when app is terminated
    messaging()
      .getInitialNotification()
      .then((remoteMessage) => {
        if (remoteMessage) {
          console.log('App launched from terminated state via notification');
          this.handleNotificationTap(remoteMessage.data);
        }
      });

    // Handle notification tap when app is in background
    const unsubscribeBackground = messaging().onNotificationOpenedApp(
      (remoteMessage) => {
        console.log('Notification tap from background:', remoteMessage);
        this.handleNotificationTap(remoteMessage.data);
      }
    );

    // Handle token refresh
    const unsubscribeTokenRefresh = messaging().onTokenRefresh((token) => {
      console.log('FCM token refreshed:', token);
      this.registerDeviceToken();
    });
  }

  private async handleForegroundMessage(remoteMessage: any): Promise<void> {
    console.log('Title:', remoteMessage.notification?.title);
    console.log('Body:', remoteMessage.notification?.body);
    console.log('Data:', remoteMessage.data);

    // Display local notification in foreground
    // You may need to use a package like 'react-native-notifee'
  }

  private handleNotificationTap(data: { [key: string]: string }): void {
    const deepLink = data.deepLink;
    if (deepLink) {
      console.log('Handling deep link:', deepLink);
      this.handleDeepLink(deepLink);
    }
  }

  private handleDeepLink(deepLink: string): void {
    // Parse deep link format: app://notification/123
    const uri = new URL(deepLink);

    if (uri.protocol === 'app:' && uri.hostname === 'notification') {
      const notificationId = uri.pathname.split('/').pop();
      if (notificationId) {
        // Navigate to notification details using React Navigation
        this.navigateToNotificationDetails(notificationId);
      }
    }
  }

  private async registerDeviceToken(): Promise<void> {
    try {
      const token = await messaging().getToken();
      if (!token) return;

      console.log('FCM Token:', token);

      const deviceType = Platform.OS === 'android' ? 'Android' : 'iOS';
      const appVersion = DeviceInfo.getVersion();

      // Call backend API
      await this.registerTokenWithBackend({
        token,
        deviceType,
        appVersion,
      });
    } catch (error) {
      console.error('Error getting FCM token:', error);
    }
  }

  private async registerTokenWithBackend(payload: {
    token: string;
    deviceType: string;
    appVersion: string;
  }): Promise<void> {
    try {
      const accessToken = AuthService.getAccessToken();
      if (!accessToken) {
        console.warn('No access token available');
        return;
      }

      await apiClient.post('/api/device-tokens/register', payload, {
        headers: {
          Authorization: `Bearer ${accessToken}`,
        },
      });

      console.log('Device token registered successfully');
    } catch (error) {
      console.error('Error registering device token with backend:', error);
    }
  }

  async unregisterDeviceToken(): Promise<void> {
    try {
      const token = await messaging().getToken();
      if (!token) return;

      const accessToken = AuthService.getAccessToken();
      if (!accessToken) return;

      await apiClient.delete(`/api/device-tokens/register/${token}`, {
        headers: {
          Authorization: `Bearer ${accessToken}`,
        },
      });

      console.log('Device token unregistered successfully');
    } catch (error) {
      console.error('Error unregistering device token:', error);
    }
  }

}
```

## Backend API Reference

### Device Token Registration

**Endpoint:** `POST /api/device-tokens/register`

**Request Body:**
```json
{
  "token": "fcm_token_abc123xyz...",
  "deviceType": "Android",
  "appVersion": "1.0.0"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Device token registered successfully",
  "data": {
    "id": 1,
    "token": "fcm_token_abc123xyz...",
    "deviceType": "Android",
    "isActive": true,
    "registeredAt": "2024-01-15T10:30:00Z"
  }
}
```

**Status Codes:**
- `200 OK` - Token registered successfully
- `400 Bad Request` - Missing or invalid fields
- `401 Unauthorized` - User not authenticated
- `500 Internal Server Error` - Server error

## Troubleshooting

### FCM Token Not Generated

**Symptom:** Console shows `FCM Token: null`

**Solutions:**
1. Verify `google-services.json` (Android) or `GoogleService-Info.plist` (iOS) present
2. Verify Firebase project ID matches in configuration
3. Check user has granted notification permissions
4. Verify app is signed correctly (iOS)

### Notifications Not Received

**Symptom:** No notifications appear in notification tray

**Solutions:**
1. Verify app has notification permission
2. Verify device token registered with backend
3. Check device is connected to network
4. Check app is not in DND (Do Not Disturb) mode
5. Verify notification channel configured (Android 8+)

### Deep Links Not Working

**Symptom:** Clicking notification doesn't navigate correctly

**Solutions:**
1. Verify deep link format: `app://notification/{id}`
2. Verify intent filter configured in AndroidManifest.xml
3. Verify URL scheme configured in Info.plist (iOS)
4. Verify deep link handler implemented in app

### Tokens Not Registering with Backend

**Symptom:** API returns 401 Unauthorized

**Solutions:**
1. Verify access token valid
2. Verify user authenticated before token registration
3. Check API endpoint accessible
4. Verify network connectivity

## Best Practices

### Token Management

✅ **DO:**
- Register token on app startup
- Register token on every login
- Unregister token on logout
- Re-register on token refresh
- Store token securely in device

❌ **DON'T:**
- Register token on every page navigation
- Store token in shared preferences unencrypted
- Ignore token refresh events
- Register same token multiple times

### Notification Handling

✅ **DO:**
- Handle both foreground and background messages
- Show local notification in foreground
- Update app UI when notification tapped
- Navigate to correct page using deep link
- Log notification events

❌ **DON'T:**
- Ignore message data payload
- Ignore notification taps
- Navigate without verifying notification exists
- Send sensitive data in notification body

### Error Handling

✅ **DO:**
- Log all errors for debugging
- Handle permission denials gracefully
- Retry registration on failure
- Show user-friendly messages
- Monitor error rates

❌ **DON'T:**
- Crash on permission denial
- Fail silently on registration error
- Retry indefinitely without backoff
- Expose server errors to users

### Security

✅ **DO:**
- Verify authentication before registering token
- Validate deep links before navigation
- Use HTTPS for all API calls
- Encrypt tokens in storage
- Implement notification preferences

❌ **DON'T:**
- Store authentication tokens in notification payload
- Accept arbitrary deep links without validation
- Use HTTP for sensitive data
- Store sensitive data in notification tray
- Ignore user notification preferences

### Performance

✅ **DO:**
- Defer token registration on app startup
- Use background handlers for background messages
- Batch notification operations
- Implement cleanup for old tokens

❌ **DON'T:**
- Block UI thread during token registration
- Handle messages synchronously
- Send duplicate notifications
- Store infinite notification history
